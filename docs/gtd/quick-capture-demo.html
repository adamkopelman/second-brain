⚡ Quick Capture

TickTick-style global shortcuts for Windows. Press a key combo in any app, type the task, and press Enter. It goes straight into this vault's 00 Inbox/ as a normal capture file. It's one PowerShell script in the system tray, so there's nothing to install.

1 · Quick add from anywhere

Press Ctrl+Alt+A while reading an email. The line under the box shows what was understood as you type. Enter saves, Shift+Enter saves and clears the box for the next task, and Esc cancels.

# 00 Inbox/2026-10-14 send-dana-the-q4-budget-draft.md --- type: inbox captured: 2026-10-14 --- - [ ] Send Dana the Q4 budget draft #computer [scheduled:: 2026-10-16] [due:: 2026-10-24]

2 · Straight onto Today

Ctrl+Alt+T adds today's date as When and tags it #next, so it shows up in the dashboard's Today list right away. If you don't type a context, it gets #anywhere, the same default the dashboard's New To-Do uses.

- [ ] Call the bank about the transfer #phone #next [scheduled:: 2026-10-14]

3 · Capture the clipboard, no popup

Left: copy something, then press Ctrl+Alt+V. A short line is saved as a task. A link or a longer snippet is saved as a note for /gtd-process-inbox. Right: right-click the tray icon for the same actions. Left-click it to open the quick-add box.

Try the quick-add syntax

This uses the same rules as the PowerShell script, ported to JavaScript for this page. "Today" is 14 Oct 2026, a Wednesday.

Syntax

TypeBecomesExamples
#taga tag: a context, a status, #evening, …#phone #waiting (adds [since:: ])
!when[scheduled:: ], the dashboard's When!today !tmr !fri !+3 !next-week !10-20 !2026-12-01
^date[due:: ], a deadline^fri ^10-31

A weekday means the next one after today. A month and day that has already passed means next year. A date word the script doesn't recognize stays in the title, and the hint shows a ⚠.
