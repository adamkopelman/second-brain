# מוח שני לראש צוות — ערכת מצגת

סשן לראשי צוות חדשים, בתוך יום של כלים. **רץ ב־45 דקות ומתכווץ ל־30.**

## הרעיון

‏70% מהיום של ראש צוות עוברים בפגישות — אבל הזמן נשרף **בתפרים** שסביבן: הכנה, סיכום, ושליפה חודשיים אחרי. המצגת בנויה על **מחזור החיים של פגישה**: לפני → במהלך → אחרי → בעוד חודשיים.

## מה יש בערכה

| קובץ | מה זה |
|------|-------|
| `slides.html` | המצגת. קובץ אחד עצמאי, עברית RTL, 12 שקופיות. נפתח בכל דפדפן, עובד גם בנייד. |
| `speaker-notes.md` | מדריך למנחה: טבלת זמנים כפולה (45 ו־30), מה להגיד בכל שקופית, הכנה ושאלות צפויות. |
| `demo-script.md` | שני הדמו החיים, כולל **ההכנה הקריטית** וערכת חירום. |
| `handout.md` | דף אחד לחלק בסוף. |

## שני דמו בלבד — וזה מכוון

| שלב | פקודה |
|-----|-------|
| לפני | `"[הפגישה] בעוד עשר דקות. מה נשאר פתוח מהפעם הקודמת?"` |
| אחרי | `/gtd-summarize-meetings` |

## לפני שמציגים

1. **לשתול פגישה קודמת ב־`Meetings/`.** בלי זה הדמו של שקופית 5 מחזיר כלום — זה השלב שהכי קל לשכוח.
2. לשתול תמליל קצר לדמו של שקופית 7.
3. חזרה גנרלית אחת + צילומי מסך כגיבוי.
4. שווה מאוד: להריץ על מידע אמיתי שלך ולהחליף את הפלטים בצילומי מסך אמיתיים.

## גבולות מול שאר היום

הסשן **לא** מלמד תיעדוף וניהול זמן (יש סשן ניהול לו״ז) ו**לא** מלמד לעבוד עם scrum/ג׳ירה (יש סשן נפרד). ג׳ירה מופיעה כאן רק כ**מקור שני לקריאה** — אותה שאלה שעבדה על פגישות, על הלוח. כאן מאבחנים איפה הזמן נשרף, לא מלמדים שיטה לנהל אותו.

## ניווט

חץ ימינה / רווח / PageDown = קדימה (תואם שלט). חץ שמאלה = אחורה. **F** = מסך מלא.
