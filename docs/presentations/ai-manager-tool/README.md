# The AI Chief of Staff — presentation kit

A ready-to-run **30-minute presentation + live demo** on using AI as a management tool, demoed on this GTD second brain.

## What's in this kit
| File | What it is |
|------|------------|
| `slides.html` | The deck. Self-contained (one file) — open in any browser, present fullscreen, works on a phone. 16 slides. |
| `speaker-notes.md` | Facilitator guide: a minute-by-minute timing map, what to say on each slide, Q&A prep, and a pre-flight checklist. |
| `demo-script.md` | The five live demos, step by step, using this vault's real skills — with a recovery kit for when the network misbehaves. |
| `handout.md` | One-page takeaway to give the audience. |

## How to present it
1. Open `slides.html` in a browser. **← / →** or click to move, **F** for fullscreen, tap left/right on a touchscreen.
2. Keep Claude Code open in this vault in a second window for the live demos.
3. Follow `speaker-notes.md` for timing; run the commands from `demo-script.md`.
4. Do the pre-flight checklist (end of `speaker-notes.md`) ~10 minutes before.

## The 30-minute arc
Premise (you have a keeping-track problem) → reframe (chatbot → operator) → the five jobs → the demo system → **five live demos** (capture, clarify, engage, meetings, review) → six more manager plays → principles → pitfalls → set-it-up → one-loop call to action.

## The demo backbone (this vault's skills)
`/gtd-capture` · `/gtd-process-inbox` · `/gtd-next-actions` · `/gtd-summarize-meetings` · `/gtd-status` · `/gtd-weekly-review` · `/gtd-dashboard`

See the vault's `README.md` and `AGENTS.md` for how the second brain itself works.

## Presenter tips
- **Don't skip the meetings demo** (Demo 4) — it's the one that sells the whole system.
- Rehearse the demos once end-to-end and screenshot each result as a network fallback.
- Bump your terminal font size so the back row can read the commands.
- If you're short on time, the compressible slides are "chatbot → operator," "why it works," and "pitfalls."
