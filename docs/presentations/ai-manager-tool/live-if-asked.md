# אם תרצה להראות משהו חי

**אין דמו מתוכנן בסשן.** המצגת עומדת בפני עצמה — כרטיסי הפלט הם מה שמדברים מעליו.

הדף הזה קיים רק למקרה שתחליט במקום לפתוח מחשב, או שמישהו יבקש לראות. שתי דקות הכנה, ואתה מכוסה.

## ההכנה היחידה (פעם אחת, לפני היום)

`Meetings/` ריקה כברירת מחדל, ובלי תוכן כל שאלה תחזיר כלום. פקודה אחת פותרת:

```bash
cp "docs/presentations/ai-manager-tool/demo-fixtures/2026-"*.md Meetings/
```

ארבע פגישות מוכנות — שתיים ישנות, אחת מלפני שבועיים, ואחת עם תמליל שעוד לא סוכם. פירוט ופקודת ניקוי ב־`demo-fixtures/README.md`.

אם לא תפתח מחשב — לא קרה כלום, זה יושב בצד.

## שלוש שאלות ששוות להראות

| אם שואלים | תקליד |
|-----------|--------|
| *"איך זה יודע מה היה בפגישה הקודמת?"* | `סנכרון עם הרמ״ד בעוד עשר דקות. מה נשאר פתוח מהפעם הקודמת?` |
| *"איך נראה סיכום אוטומטי?"* | `/gtd-summarize-meetings` |
| *"מה זה בכלל רואה?"* | `/gtd-status` |

השלישית היא הכי בטוחה — היא לא תלויה בכלום ותמיד מחזירה משהו.

## שתי עובדות שכדאי שתדע לפני שאתה פותח מחשב

1. **הסיכום לא ממציא תמליל.** הוא מסכם רק את מה שכתוב בסעיף `## Transcript`, ורק בקבצים עם `transcription_status: done` ו־`summary_status` ששונה מ־done. אין קובץ כזה — הוא יגיד "אין פגישות לא מסוכמות".
2. **הוא עונה בשפת התמליל.** התמלילים בקבצים המוכנים בעברית, ולכן גם הפלט יחזור בעברית.

## אם משהו נופל מול הקהל

תסגור את המחשב ותחזור למצגת. הכרטיסים שם ממילא מראים את אותו דבר — זו בדיוק הסיבה שאין דמו מתוכנן.
