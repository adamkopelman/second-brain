## שקופית 5 · לפני — **חי**

**מה אומרים:** "יש לי סנכרון עם הרמ״ד בעוד עשר דקות. מה אני עושה היום? נכנס ומנסה להיזכר."

**מה מקלידים:**
```
סנכרון עם הרמ״ד בעוד עשר דקות. מה נשאר פתוח מהפעם הקודמת?
```

**על מה להצביע:**
- מה שנשאר פתוח — ובעיקר **"נדחתה פעמיים"**
- מה שהשתנה מאז (תקלה, החלטה מפגישה אחרת)
- סדר היום המוצע

**המשפט לסיום:** *"שום דבר חדש לא נכתב פה. זה רק מה שכבר תועד. ולכן — זה עובד רק אם עשיתי את שלב 'אחרי'."*

---

## שקופית 7 · אחרי — **חי** · הדמו החשוב

**מה אומרים:** "הדבר הכי גרוע שאפשר לעשות עם פגישה זה לזכור אותה."

**מה מקלידים:**
```
/gtd-summarize-meetings
```

**על מה להצביע — לפי הסדר:**
1. **החלטות** — לא סיכום, החלטות.
2. **משימות עם אחראי** — שם ליד כל שורה.
3. **"ממתין ל…"** ← תעצור כאן. זו השורה שמוכרת את הסשן. *"זה מה שמפסיק אותך לרדוף אחרי אנשים מהזיכרון."*
4. השורה האחרונה — שזה **נשמר**, ושהכרטיס של דנה התעדכן לבד.

**אם יש לך זמן לדמו אחד בלבד — זה הוא.**

## שקופית 9 · ג׳ירה — **מוצג**

אין כאן דמו חי, ובכוונה: `jira-mcp` הוא שרת MCP שנותן למודל גישת **קריאה** לג׳ירה, והוא לא חלק מה־vault. מציגים פלט ומדברים.

**איך לפתוח:** *"לעבוד עם ג׳ירה תלמדו בסשן אחר. אני רק רוצה להראות מה קורה כשמישהו קורא אותה במקום להסתכל עליה."*

**על מה להצביע:** השורה על דנה — 22 CR, פי 3 מכל אחד אחר. *"זו בעיה של אנשים. הלוח לעולם לא יעלה אותה לבד, והנתונים ישבו שם כל הזמן."*

**אם תרצה כן להריץ חי:** צריך לחבר `jira-mcp` מראש ולוודא שהפרויקט שלך נגיש לו. שווה רק אם הספקת לבדוק את זה יום לפני.
